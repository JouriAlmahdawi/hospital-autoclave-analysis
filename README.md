Hospital Autoclave Analysis#
Project Description
This project analyzes the performance of a hospital autoclave sterilization system using Python.
The analysis studies how physical variables affect sterilization efficiency.
Variables used
-Temperature (°C)
-Pressure (bar)
-Time (minutes)
-Energy consumption (kWh)
-Sterilization efficiency (%)
Goals
Understand relationships between physical variables
Visualize system behavior using data plots
Evaluate sterilization efficiency
Tools
Python
Pandas
Matplotlib
Author
Physics Student
